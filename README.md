# 天津大学《玩转生成式 AI》线上作业 4–5

作者：磨帅齐

## 模块四

`index.html`：学期行动与机会系统。

- 8 个行动字段
- 表格、看板、截止时间线三种视图
- 本地可新增、推进、删除任务
- AI 初筛建议与人工确认状态
- 提交助手：`submit4.html`

## 模块五

`module5/index.html`：洪澜 WorkBuddy 展示页。

- 任务卡、背景卡与角色卡
- 工作规则和不可越过的边界
- 可复制的完整启动提示词
- 一次具体失败与修订测试
- 提交助手：`submit5.html`

## 说明

模块五允许提交 WorkBuddy 或可访问展示链接，因此使用静态展示页提交。模块四的正式作品链接应为飞书多维表格；本仓库中的数据应用用于展示字段、视图与 AI 交互结构。
